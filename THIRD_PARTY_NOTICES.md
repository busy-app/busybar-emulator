## Getting the sources

- **The emulator:** https://github.com/busy-app/busybar-emulator/tree/v0.1.0-beta.2, the release tag of this version in the public repository. The sources of the WebAssembly modules are there: the stubs (`packages/engine/native`), the changes made to the firmware's code (`packages/engine/patches.mjs`) and the build script (`packages/engine/build.mjs`), which builds the modules from the firmware commits below.
- **The firmware:** https://github.com/busy-app/busybar-firmware, with its submodules at the commits listed below.
- The source code of the release is offered from the same place as the release itself.

## The firmware inside the emulator

The emulator runs code of the BUSY Bar firmware, compiled to WebAssembly (`runtime.wasm`: the JavaScript runtime; `screen.wasm`: the displays, the GUI and the system programs), with Emscripten 7.0.0. The firmware's own code is GNU General Public License v2.0 or later (© 2024-2026 Flipper FZCO), by the firmware's REUSE.toml.
